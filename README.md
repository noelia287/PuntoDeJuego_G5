# Etapa 1 · Portal estático
Abre index.html con el navegador. Para observar HTTP, desde esta carpeta ejecuta:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```
Visita http://127.0.0.1:8000. Detén el servidor con Ctrl+C. Es una demostración local; La instalación de Apache será el siguiente paso del despliegue.

Personalizad nombre, textos, juegos y CSS. Mantened la navegación. La clasificación es texto HTML: cambiar un resultado no recalcula puntos. Todos los datos son ficticios.
